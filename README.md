# تطبيق قياس معدل الذكاء (IQ Test App)

## 📱 نبذة عن التطبيق
تطبيق ويب تفاعلي لقياس معدل الذكاء من خلال 20 سؤال متنوع يغطي:
- ✅ أسئلة رياضية
- ✅ أسئلة منطق
- ✅ أسئلة لغة
- ✅ أسئلة إدراك بصري

## ✨ المميزات
- 🧠 واجهة مستخدم جميلة وتفاعلية
- ⏱️ مؤقت لمدة 30 دقيقة
- 📊 حساب تلقائي لمعدل الذكاء
- 💾 حفظ النتائج محلياً (Local Storage)
- 📈 عرض الإحصائيات والنتائج السابقة
- 🔄 إمكانية العودة للأسئلة السابقة
- 📄 حفظ النتائج على Google Sheets (اختياري)
- 🌐 دعم الواجهة العربية بالكامل

## 🚀 كيفية الاستخدام

### الخطوة 1: تحميل المشروع
```bash
git clone https://github.com/alwaliddsm-alt/iq-test-app.git
cd iq-test-app
```

### الخطوة 2: فتح التطبيق
افتح ملف `index.html` في متصفحك

### الخطوة 3: البدء بالاختبار
1. أدخل اسمك
2. اضغط على "ابدأ الاختبار"
3. أجب على جميع الأسئلة
4. اضغط "إنهاء الاختبار" عند الانتهاء

## 📊 كيفية حفظ النتائج على Google Sheets

### الخطوة 1: إنشاء نموذج Google Form
1. اذهب إلى [Google Forms](https://forms.google.com)
2. أنشئ نموذج جديد بالحقول:
   - الاسم (Name)
   - معدل الذكاء (IQ Score)
   - النسبة المئوية (Percentage)
   - الوقت المستغرق (Time Spent)

### الخطوة 2: الحصول على رابط النموذج
1. في النموذج، اضغط على "إرسال"
2. انسخ رابط النموذج

### الخطوة 3: تحديث الكود
عدّل السطر في `script.js`:
```javascript
const googleFormURL = 'YOUR_FORM_URL';
```

التطبيق يستخدم `localStorage` لحفظ:

- التواريخ والأوقات
