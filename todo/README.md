# تطبيق قائمة المهام (To-Do List App)

## 🎯 نبذة عن التطبيق

تطبيق ويب تفاعلي لإدارة المهام اليومية مع إمكانية حفظ البيانات محليًا في المتصفح. يتضمن واجهة سهلة الاستخدام وميزات متقدمة.

## ✨ المميزات الرئيسية

✅ **إدارة المهام**
- إضافة مهام جديدة
- تعديل المهام الموجودة
- حذف المهام
- تحديد المهام المكتملة

✅ **التصنيفات**
- 🏢 عمل
- 👤 شخصي
- 🛒 تسوق
- 💪 صحة
- 📌 أخرى

✅ **الفلاتر والبحث**
- عرض جميع المهام
- عرض المهام المتبقية فقط
- عرض المهام المكتملة فقط
- البحث عن مهمة معينة

✅ **الإحصائيات**
- عدد المهام الكلي
- عدد المهام المكتملة
- عدد المهام المتبقية
- نسبة الإنجاز
- شريط تقدم مرئي

✅ **الميزات الإضافية**
- 🌙 وضع ليلي (Dark Mode)
- 💾 حفظ تلقائي في Local Storage
- ⏱️ عرض وقت الإنشاء والإنجاز
- 🔄 ترتيب المهام
- 🗑️ حذف جميع المهام المكتملة
- 📱 تصميم يدعم الهواتف الذكية

## 🚀 كيفية الاستخدام

### 1. فتح التطبيق
```bash
# استنسخ المستودع
git clone https://github.com/alwaliddsm-alt/iq-test-app.git
cd iq-test-app/todo

# افتح index.html في المتصفح
```

### 2. إضافة مهمة
1. اكتب المهمة في حقل الإدخال
2. اختر التصنيف (اختياري)
3. اضغط زر "إضافة" أو اضغط Enter

### 3. تعديل مهمة
1. اضغط على أيقونة التعديل 📝
2. عدّل نص المهمة والتصنيف
3. اضغط "حفظ"

### 4. حذف مهمة
1. اضغط على أيقونة الحذف 🗑️
2. أكد عملية الحذف

### 5. تحديد مهمة كمكتملة
1. اضغط على صندوق الاختيار ☑️
2. ستظهر المهمة كمكتملة مع شطب النص

## 💾 كيفية عمل التخزين المحلي

### حفظ البيانات
```javascript
// عند إضافة/تعديل/حذف مهمة
localStorage.setItem('tasks', JSON.stringify(tasks));
```

### استرجاع البيانات
```javascript
// عند فتح التطبيق
const saved = localStorage.getItem('tasks');
if (saved) {
    tasks = JSON.parse(saved);
}
```

### مميزات Local Storage
- ✅ حفظ دائم: البيانات تبقى حتى بعد إغلاق المتصفح
- ✅ سريع: لا توجد تأخيرات في التحميل
- ✅ آمن: البيانات محلية على جهازك فقط
- ✅ لا توجد نسخة احتياطية تلقائية

## 🐛 استكشاف الأخطاء

### المهام لا تحفظ
- تحقق من أن Local Storage مفعل في المتصفح
- جرب مسح الكوكيز وأعد تحميل الصفحة

### النموذج لا يظهر
- تأكد من أن JavaScript مفعل
- جرب في متصفح مختلف

### مشكلة في التصميم
- أعد تحميل الصفحة (Ctrl + F5)
- امسح ذاكرة التخزين المؤقت للمتصفح
